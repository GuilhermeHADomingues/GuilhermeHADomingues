## 👨‍💻 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas** e estou construindo minha base em **backend com Java**. Meu foco é aprender do jeito certo: entender o *porquê* de cada conceito de POO, escrever código legível e praticar com exercícios reais, com menus de console, validações e regras de negócio.

- 🎓 Cursando **ADS** no Centro Universitário Facens
- 📖 Estudando POO em Java de forma estruturada, uma lição por vez
- 🗄️ Aprendendo **Banco de Dados** e normalização até a 3FN
- 🎯 Objetivo: conquistar minha primeira oportunidade como desenvolvedor backend Java
